# spec-mirror-infisical

A git mirror of Infisical's [OpenAPI spec](https://app.infisical.com/api/docs/json). The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-infisical.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
