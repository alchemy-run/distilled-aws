# spec-mirror-auth0

A git mirror of Auth0's [Management API OpenAPI spec](https://auth0.com/docs/api/management/openapi.json). The spec is fetched and committed as a JSON file so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-auth0.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
