# spec-mirror-inngest

A git mirror of Inngest's [REST API OpenAPI specs](https://api-docs.inngest.com/api-specs/v2.json). The specs are fetched and committed as JSON files so the repo serves as a versioned snapshot.

The mirror is updated every 24 hours and is designed to be used as a stable git submodule.

## Usage as a submodule

```sh
git submodule add https://github.com/distilled-mirror/spec-mirror-inngest.git
```

## Updating specs

From `.meta/`:

```sh
bun install
bun run fetch-specs
```
